
# 🌟 VisageVault – Face Detection Android App

🔐 VisageVault is an intelligent and sleek Android application powered by ML Kit’s Face Detection API, capable of detecting facial features such as eye movement, smile intensity, and emotions — all in real-time.

## Features

✨ Features
🚀 Modern Splash Screen — Elegant and engaging entry animation.

👁️ Real-Time Face Detection — Detects eyes (open/closed), smile, and emotional expressions using your camera.

🧠 Emotion Insight — Reads subtle emotional cues from facial expressions.

🧼 Simple & Sober UI — Clean design for a smooth user experience.

📱 Built with Java/Kotlin — Native performance with a modern tech stack.

🧭 User-Friendly — Just install and go — no complex setup required.
